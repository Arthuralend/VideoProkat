# ВидеоПрокат — Android TV

Огромный выбор фильмов, сериалов, мультфильмов для детей и взрослых, тв-шоу и познавательных программ — в плеере на телевизоре.

## Установка

Готовый APK: **Releases → последняя версия → `VPortal.apk`**
Прямая ссылка (удобно для приложения Downloader на ТВ):
`https://github.com/Arthuralend/VPortal/releases/latest/download/VPortal.apk`

Новые версии ставятся поверх старых: все сборки подписаны одним ключом.

## Подключение

На первом экране введите код **22184**: приложение подключится само. Строка подключения к медиатеке
встроена в приложение и пользователю не показывается (в диагностике адрес и ключ скрыты).

Протокол VPortal: только POST-запросы на адрес API, тело JSON с полями `key`, `mac`, `app` и параметрами запроса
(`cmd: flicks / flick / search`, `fid`, `offset`, `limit`), ключ также в заголовке `X-Api-Key`.
Приложение перебирает варианты тела (json / json только с ключом / как OTT Navigator / form) и запоминает рабочий.

## Возможности

- Меню слева, перелистывается пультом; наведение на раздел сразу его открывает
- Сетка постеров с подгрузкой следующих страниц
- Поиск, «Продолжить просмотр», «Избранное»
- Карточка фильма с описанием; «Продолжить с …» / «С начала»
- Плеер ExoPlayer (HLS, DASH, MP4, MKV): ← / → перематывают на 10 с, OK ставит на паузу
- Разделы, жанры и годы берутся из медиатеки; сериалы — с сезонами и сериями; выбор качества
- **Диагностика**: DNS и ответы портала на каждый вариант запроса (ключ скрыт)

## Сборка

GitHub Actions собирает APK при каждом push в `main` (`.github/workflows/build.yml`).
Локально: `gradle assembleRelease` (Gradle 8.7, JDK 17, Android SDK 34).

## Структура

- `data/PortalConfig.kt` — разбор строки `portal::[key:…]url`
- `data/PortalClient.kt` — клиент API VPortal: разделы, списки, карточки, поиск, мягкий разбор JSON
- `data/Diagnostics.kt` — проверка связи
- `ui/` — экраны на Jetpack Compose
